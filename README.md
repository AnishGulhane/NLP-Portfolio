# Natural Language Processing (NLP) Portfolio

This repository contains a collection of Natural Language Processing projects demonstrating text preprocessing, sentiment analysis, and machine learning techniques.

##  Projects Included

### 1. Spam Detection Model
**File:** `Spam_Detection_Model.ipynb`
* **Overview:** A binary classification model utilizing NLTK and Scikit-learn to successfully distinguish between spam and normal messages.
* **Techniques:** Text preprocessing, stop-word removal, and Bag-of-Words modeling using `CountVectorizer`.
* **Outcome:** Achieved 98% accuracy using a Logistic Regression classifier.

### 2. IMDB Movie Review Sentiment
**File:** `IMDB_Movie_Review_Sentiment.ipynb`
* **Overview:** Sentiment analysis pipeline applied to a dataset of movie reviews to classify text as positive or negative.
* **Techniques:** Compares multiple classification algorithms (Logistic Regression, Decision Trees, Random Forests) alongside rule-based lexicon evaluation using NLTK VADER.

### 3. India Budget Word Cloud
**File:** `India_Budget_Word_Cloud.ipynb`
* **Overview:** An exploratory data analysis (EDA) project generating visual insights from official text documents.
* **Techniques:** Demonstrates automated text extraction directly from PDF documents using `PyPDF2`, with data visualization handled via `WordCloud` and `Matplotlib`.
